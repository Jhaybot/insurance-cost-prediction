# Insurance Cost Prediction

## Project Overview

This project uses machine learning to predict individual medical insurance costs based on demographic and lifestyle characteristics.

## Objectives

- Explore and understand the insurance dataset.
- Perform data cleaning and exploratory data analysis.
- Apply feature engineering and preprocessing.
- Train and evaluate machine learning regression models.
- Build a predictive application.

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Git and GitHub
